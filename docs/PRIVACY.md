# 隐私设计

## 本地保存内容

宠物档案、提醒、健康/体重记录、成长时间轴、费用、照片、附件和设置保存在应用沙盒中的 SQLite 数据库与私有文件目录。应用无需账号，不包含业务后端、广告 SDK 或分析 SDK。

## 权限

- **通知**：只用于用户创建的本地护理提醒；拒绝后记录功能仍可使用。
- **相机**：仅在用户主动选择拍摄时申请。
- **照片**：使用 Android 系统 Photo Picker，应用只读取用户选中的项目并复制到私有目录，不申请整个照片库读取权限。
- **存储访问框架**：由用户主动选择备份保存位置或恢复文件。

应用明确阻止位置、通讯录、电话、麦克风和宽泛媒体库权限。

## 数据离开设备的时机

只有用户主动使用系统分享/文件选择界面导出 `.pawzip` 备份、分享资料或把 APK/备份复制到其他位置时，数据才离开应用私有目录。目标应用、网盘或文件夹由用户选择；项目无法控制导出后的副本。

## 删除与迁移

应用内删除先进入 30 天回收站。卸载 Android 应用会删除其私有数据；如需迁移或重装恢复，必须在卸载前导出完整备份并妥善保管。
