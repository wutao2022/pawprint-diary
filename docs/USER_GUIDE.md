# 新手使用说明

## 第一次使用

打开 APP 后先在“档案”或首页引导中创建宠物，填写名称、物种和可选的生日/到家日期。随后可添加 1–5 张照片并选择主图。多宠物用户可从页面顶部切换宠物；所有记录会跟随当前宠物切换。

## 四个入口

- **今天**：查看即将到期或逾期的护理事项，完成、稍后或跳过。
- **日历**：按日期查看提醒、健康和成长记录。
- **成长**：记录照片、地点和故事，形成独立时间轴。
- **档案**：管理宠物资料、照片、健康/体重记录和附件。

底部中央悬浮 `＋` 用于快速新增提醒、健康记录、体重、成长瞬间或附件。

## 提醒与通知

新增护理提醒时选择类别、日期、提前天数和可选周期。允许通知权限后，系统会在本机安排提醒；拒绝权限不会丢失事项，今天页仍会展示。完成周期任务会保留历史并创建下一次待办。

## 照片与附件

选图会打开 Android 系统 Photo Picker，其中可看到系统媒体库及系统接入的云端来源；应用只能读取你明确选中的项目。拍照时才会申请相机权限。选定文件会复制到应用私有目录，因此原图后续移动通常不影响 APP 内副本。

## 备份与恢复

在设置/数据工具中选择“一键导出完整备份”或“保存备份到本地文件夹”。`.pawzip` 包含数据库、宠物照片、成长照片和资料附件。恢复会替换当前数据，因此先确认备份文件来源；应用会在替换前保存快照，校验失败自动回滚。

## 常见问题

**卸载后数据还在吗？** 不在。Android 会清除应用私有目录，请先导出备份。

**不授权通知还能用吗？** 可以，所有记录和首页待办仍可用，只是没有系统弹出的本地通知。

**为什么不申请整个相册权限？** 系统 Photo Picker 能让用户从相册选择照片，同时只把选中项授权给 APP，隐私范围更小。

**数据会自动上传吗？** 不会。只有你主动导出或分享时，所选内容才离开应用私有目录。
